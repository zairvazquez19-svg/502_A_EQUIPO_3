## Cómo revisar el v3

1. Abre `v3_actual/prototipo_v3.html` con doble clic. No necesita instalar nada.
2. En la pestaña **Verificación** se ve el resultado de CA-01 a CA-15.
3. Para encontrar un cambio concreto, usa la tabla «Cómo ubicar cada cambio» de `CAMBIOS_v3.md`. Indica qué rol elegir y a qué pestaña entrar.
